# Mebel3D — 3D-конструктор корпусной мебели и кухонь

Интерактивный веб-конструктор и расчетный комплекс для проектирования корпусной мебели (кухонные гарнитуры, шкафы, пеналы, комоды) с автоматической генерацией деталировки, карт раскроя, сборочных чертежей и сметы по стандартам мебельного производства.

![Mebel3D Preview](public/apple-touch-icon.png)

---

## Возможности

### 1. 3D-визуализация и управление
- **Three.js движок**: физически корректный рендеринг (PBR) с динамическими тенями и процедурными текстурами материалов (Egger, Kronospan, AGT).
- **Интерактивные анимации фасадов**: распахивание створок на петлях с доводчиками, выдвижение ящиков скрытого монтажа, сдвижные створки купе.
- **Инженерные 3D-размеры**: размерные цепочки и засечки (габариты модулей W x H x D, общая длина линии кухни).
- **Защита от коллизий**: автоматическое определение стороны петель (дверцы у стены распахиваются в комнату, а не в стену).
- **Перетаскивание модулей в 3D** с магнитной привязкой (snap) без щелей.

### 2. Реалистичный мебельный конструктив
- **Модуль мойки (`sink`)**: силовые царги 90 мм вместо сплошной крышки под врезную чашу + сантехнический просвет сзади под коммуникации.
- **Модуль духового шкафа (`oven`)**: открытая вентиляционная ниша за ТЭНами + выдвижной ящик под противни снизу.
- **Фальшпанели и доборы (`isFiller`, <= 120 мм)**: фасадная планка в единой плоскости гарнитура + монтажный брус жесткости.
- **Единый цоколь по кругу**: передний цоколь без щелей + боковые планки, закрывающие опоры с торцов.
- **Многоярусные кухни (европейский портал)**:
  - 1-й ярус: тумбы 820 мм + влагостойкая столешница 38 мм.
  - 2-й ярус: навесные шкафы 720 мм (глубина 320 мм).
  - 3-й ярус: глубокие антресоли 360 мм (глубина 560 мм вровень с пеналом) с системой Push-to-open.
  - Пенал 2530 мм: монолитный шкаф в единую верхнюю линию под потолок.

### 3. Производственная документация и расчеты
- **Смета и калькуляция**: автоматический расчет стоимости ЛДСП, МДФ, кромки, столешниц и фурнитуры (петли, конфирматы, эксцентрики, направляющие).
- **Деталировка и раскрой**: размеры деталей с учетом толщины плиты (16/18 мм), припусков и кромкования.
- **Сборочные чертежи**: схемы сверления (присадки) под евровинты и эксцентриковые стяжки.
- **Экспорт**: сохранение проектов в JSON, экспорт в GLTF/GLB для AR и 3D-печати.

## Технологический стек

- **Core**: TypeScript, HTML5, CSS3 (Vanilla design tokens, dark HUD, glassmorphism)
- **3D Graphics**: Three.js (r183), WebGL 2.0
- **Bundler & Dev Server**: Vite 8
- **Тестирование**: `tsx scripts/check.ts` (автоматическая валидация геометрии, формул раскроя и наложения деталей)

## Быстрый старт

### Требования
- Node.js v18+ или v20+
- npm / yarn / pnpm

### Установка и запуск

```bash
git clone https://github.com/ttamii/MB3D.git
cd MB3D

npm install
npm run dev
```

После запуска приложение доступно по адресам:
- Конструктор: http://localhost:5173/constructor.html
- Лендинг: http://localhost:5173/

### Сборка и проверка качества

```bash
npm run check
npm run build
npm run preview
```

## Структура проекта

```
MB3D/
├── constructor.html        # Точка входа веб-конструктора
├── index.html              # Главная страница / презентация
├── public/                 # Статические ассеты (иконки, фавиконки)
├── scripts/
│   └── check.ts            # Headless-тесты геометрии и валидации
├── src/
│   ├── app/
│   │   ├── main.ts         # Инициализация интерфейса и жизненного цикла
│   │   └── store.ts        # Реактивное состояние проекта и истории (Undo/Redo)
│   ├── core/
│   │   ├── blueprint.ts    # Генерация 2D сборочных чертежей
│   │   ├── cutlist.ts      # Формирование карт раскроя и списков панелей
│   │   ├── defaults.ts     # Пресеты модулей, материалы, константы и лимиты
│   │   ├── drilling.ts     # Расчет присадочных отверстий (сверление)
│   │   ├── estimate.ts     # Расчет себестоимости и коммерческой сметы
│   │   ├── geometry.ts     # Параметрическое построение 3D-геометрии мебели
│   │   ├── kitchenWizard.ts# Генератор планировок (автоматическая кухня)
│   │   ├── room.ts         # Параметры помещения, стен, дверей и окон
│   │   ├── storage.ts      # Сериализация, экспорт и локальное хранилище
│   │   ├── types.ts        # TypeScript интерфейсы и доменные модели
│   │   └── validate.ts     # Валидация и нормализация данных проекта
│   ├── styles/
│   │   └── app.css         # Стили интерфейса, диалогов и HUD
│   ├── three/
│   │   ├── textures.ts     # Процедурные текстуры древесных пор и камня
│   │   └── viewer.ts       # Three.js сцена, камера, освещение, размеры, рэйкастинг
│   └── ui/
│       ├── contextMenu.ts  # Контекстное меню по правому клику
│       ├── dialogs.ts      # Модальные окна (чертежи, раскрой, смета, мастер кухни)
│       ├── dom.ts          # Легковесный DOM-хелпер
│       └── panels.ts       # Левая (модули) и правая (свойства) панели управления
├── package.json
├── tsconfig.json
└── vite.config.ts
```
